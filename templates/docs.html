02

Protocol

Authorization Code with PKCE

  1. 1
    Create a verifier

    Generate a high-entropy verifier and its S256 challenge.

  2. 2
    Authorize

    Send the browser with an exact redirect URI, state, scopes, nonce when required, and the challenge.

  3. 3
    Exchange once

    POST the short-lived code and original verifier to the token endpoint.

  4. 4
    Validate

    Verify the ID token signature, issuer, audience, expiry, and nonce.
